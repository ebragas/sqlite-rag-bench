# System Decisions and Tuning Registry

Living reference of core design choices, rejected or deferred alternatives, whether each choice is tunable during experimentation, and the exact eval signal that justifies changing it.

| Component | Current Decision | Other Options | Tunable? | When to Explore Tuning |
| :--- | :--- | :--- | :--- | :--- |
| **Scoring rubric** (`ADR-0001`) | `0.70 * Answer Score + 0.30 * Citation Score`, strict Onyx zeroing on wrong claims, citation F1 | Soft partial credit on errors; 80/20 weights; unweighted average | No (locked metric) | Never tune mid-experiment; changing the ruler invalidates comparisons. |
| **Responder & Judge tiers** (`ADR-0001`) | Distinct `Judge !== Responder`; Fast or Decision Model Judge on `dev`, Frontier (or >= 90% calibrated) Judge on `val`/`holdout` | Same-family Judge; Decision Model (`clef:27b` / TypeSafe Jev) on `dev` | Yes (`routingModel`, `synthesisModel`, `judgeModel`) | Sweep Responder models during hill-climbing; use Decision Model Judge on `dev` only after `calibrate-judge` hits >= 90% contradiction agreement. |
| **Canonical text rendering** | Metadata header + `content_field_names` + any remaining non-empty text fields | Strict `content_field_names` only; raw JSON dump | Limited | Revisit if `dev` traces show key fields omitted or noisy JSON fields hurting BM25 precision. |
| **Dual-granularity chunking** | Short docs (`<= 6,000` chars) whole; long docs split structurally (`~4,000` chars, `~600` overlap) + header card | Fixed-token sliding window; smaller chunks (`1,500` chars); parent-child sub-chunks; no header card | Yes (`chunkStrategy`, target size, overlap) | Tune when `dev`/`val` retrieval misses facts buried inside long Fireflies transcripts, Confluence pages, or Drive docs. |
| **FTS5 BM25 indexing** | External-content SQLite FTS5 (`porter unicode61`) with separate `(title, metadata_text, body)` columns | Single merged text column; `unicode61` without Porter stemming; trigram tokenizer | Yes (column BM25 weights, `topK`) | Tune if exact code symbols, ticket IDs, or title matches rank below noisy body text. |
| **Dense vector storage & dims** (`ADR-0002`) | Uncompressed L2-normalized `Float32Array` in RAM, `gemini-embedding-001` at `768` dims | `int8` quantization; `1536` or `3072` dims; HNSW / external vector DB | Yes (`embeddingModel`, `embeddingDims`) | Test `1536` dims if L2 vector recall lags on multi-doc `val` items; consider `int8` only if RSS approaches 4 GB. |
| **Link Graph & Ontology** | Deterministic `graph_edges` (`explicit_field` 1.0, `regex_mention` 0.6) + 6-type `entity_mentions` + `source_schema_catalog` | Targeted LLM/Decision Model prose relation extraction (`reports_to`, `chose`); CSR Personalized PageRank | Yes (edge weights, hop depth, optional PPR) | Add PPR or targeted prose triple extraction only if `val` multi-doc errors trace back to missing implicit links. |
| **Observability backend** (`ADR-0001`) | Opt-in AI SDK v6 OpenTelemetry -> Langfuse Cloud Hobby (50K units/mo); terminal scorecard when keys absent | Self-hosted Langfuse v3 (6 containers); PostHog OTel; local Arize Phoenix; static HTML | Yes (env-var switch) | Move to self-hosted Langfuse or Phoenix only if dev sweeps approach the 50K monthly unit limit. |
| **Agent entry & tool ladder** | Start at L0 (0 tools); gate `preSearchEnabled` (default `false`) and 4 tools (`search`, `fetch_docs`, `filter_metadata`, `expand_graph`) via config | Always-on search-first; 5+ tools including separate `count_docs`; raw SQL tool | Yes (`preSearchEnabled`, `enabledTools`) | Enable each tool and `preSearchEnabled` step by step only when `dev`/`val` proves a gain above judge noise. |
| **Agent loop budgets** | `maxAgentTurns = 6`, `maxFetchedDocs = 15`, `softDeadlineMs = 90000`, stateless concurrency-4 + bounded Gemini retry | Lower turns (`3 to 4`) for speed; higher cap (`10 turns`, `25 docs`) for complex multi-doc queries | Yes (`maxAgentTurns`, `maxFetchedDocs`, `softDeadlineMs`) | Increase if multi-doc traces hit turn/doc caps before finding all sources; decrease if p95 latency nears 60s. |
| **Adjudication & Abstention** | Prompt-level **Governing Record** priority + strict outcome-level **Abstention** + partial-unanswerability rules | Dedicated **Decision Model** (`clef-flash` / Jev) abstention gate before synthesis | Yes (prompt rules; optional gate flag) | Add a separate abstention gate only if `val` shows Abstention Recall < 100% or high **False Abstention** rate. |
| **Citation pruning** | Structured `zod` synthesis output (`supporting_doc_ids`) + deterministic corpus/read-set filter + forced `[]` on **Abstention** | Second-pass LLM or **Decision Model** (`clef-flash` / Jev) citation pruner; claim-to-citation mapping | Yes (optional pruner pass flag) | Add a second-pass pruner only if `val` shows low **Citation Precision** from extra retrieved docs slipping into `document_ids`. |
| **Run Profiles & Langfuse tracking** | Typed `zod` **Run Profile** JSON presets (`eval/profiles/`) + `--set` CLI overrides + immutable `eval/runs/` manifests + Langfuse `runExperiment` on local split arrays with HTTP `traceparent` | Env-var-only config; hosted Langfuse cloud datasets (risks leaking `holdout`); hardcoded constants | Yes (`--profile`, `--set`, `BRAIN_PROFILE`) | Pin one winning production profile in `./serve`; use `eval/profiles/` presets for every rung and knob sweep. |
| **Promotion Gate & Split Discipline** | Measure `L0` **Judge** noise floor (2x `dev`); promote only if `dev` > noise band (`>= +0.02`), `val` holds/improves, 0 **Invalid Citations**, **Abstention** recall holds, p95 `<= 60s`; fixed splits across ladder | Dev-only promotion; re-seeding `dev`/`val` every round | Limited (noise threshold, `--preserve-holdout` sanity re-seed) | Re-seed `dev`/`val` with `--preserve-holdout` only as a late sanity check; run locked `holdout` once at the end. |
| **Spend Ledger & Guardrails** | Single configurable `EVAL_BUDGET_USD` cap (default `40`) in `eval/spend-ledger.jsonl`, tagged by cost bucket (`embedding`, `responder`, `judge`) and `split`; cached SQLite DBs per index config hash | Rigid hardcoded sub-bucket caps; full grid search across index + query + model | Yes (`--budget`, optional per-bucket cap flags) | Raise `EVAL_BUDGET_USD` explicitly if high-value sweeps justify more spend; add a per-bucket cap flag only if one stage runs hot. |
| **Node 20+ packaging & `./serve`** | Pin `better-sqlite3` to `12.9.0` (Node 20 to 25 prebuilds, zero C++ toolchain); move pure-JS `typescript`, `@types/node`, and `@types/better-sqlite3` to `dependencies`; `./serve` runs `npm ci --omit=dev`, `tsc -p tsconfig.build.json`, `exec node dist/server.js` | Keep `12.11.1` + Docker fallback on Node < 22; always run inside Docker `node:22-slim`; bundle with `esbuild`; commit `dist/` | No (contract compatibility) | Revisit only if the target container runtime moves to bare Linux Node 26 without build tools. |
